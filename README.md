# Loan Application System

A modern web-based Loan Application System built using React.js that streamlines the loan application process through a multi-step form workflow, document uploads, co-applicant management, and e-signature functionality.

## Overview

This application allows users to apply for loans through an intuitive and user-friendly interface. The system validates user inputs, collects applicant details, supports document uploads, and enables electronic signatures for a seamless loan application experience.

## Features

### Applicant Information

* Personal information collection
* Contact details management
* Address information with validation
* Employment and income details

### Co-Applicant Support

* Add co-applicant information
* Relationship management
* Joint application workflow

### Document Management

* Upload supporting documents
* File validation
* Secure document handling

### E-Signature

* Digital signature capture
* Signature validation
* Agreement confirmation

### Form Validation

* Required field checks
* Error handling and user feedback

### Testing

## Installation

### Clone the Repository

```bash
git clone https://github.com/Supreeth-AL/loan-application-system.git
```

### Navigate to Project

```bash
cd loan-application-system
```

### Install Dependencies

```bash
npm install
```

### Run the Application

```bash
npm run dev
```

### Run Cypress Tests

```bash
npx cypress open
```
